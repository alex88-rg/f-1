# Personal Fitness Planner PWA

Локальная веб-версия приложения.

## Важно
Для установки на iPhone как PWA приложение должно открываться по HTTPS. Сам файл `index.html` из «Файлов» можно открыть для просмотра, но установка «На экран Домой» и Service Worker нормально работают при размещении сайта на HTTPS.

## Локальные данные
Результаты сохраняются в localStorage браузера. Серверная база не используется.

## Функции MVP
Сегодня, календарь, 16-недельный план, чек-листы, завершение тренировки, бег, вес, прогресс, экспорт JSON и тёмная тема.

Для публикации достаточно загрузить эти файлы на любой HTTPS-хостинг статического сайта.
