# Fitness Planner Universal v2

Это не косметическая версия Pro: архитектура и поведение расширены под универсальный фитнес-планировщик.

Новое в v2:
- универсальные программы без привязки к числу недель;
- несколько программ и активная программа;
- конструктор шаблонов тренировок;
- блоки упражнений, кардио, интервалы, разминка и заминка;
- добавление/дублирование шаблонов;
- пошаговый режим старта тренировки с таймером;
- силовые подходы: вес, повторы, выполнение, добавление подходов;
- история фактических результатов;
- RPE, энергия, заметки;
- тренировки и расписание;
- календарь с состояниями;
- кардио-факт: минуты, дистанция, темп;
- цели и привычки;
- вес и история измерений;
- серия завершённых тренировок;
- импорт/экспорт JSON;
- тёмная тема;
- offline PWA;
- локальное хранение без аккаунта и сервера.

Для iPhone опубликовать файлы на HTTPS и открыть URL в Safari → Поделиться → На экран «Домой».
