# Fitness Planner Universal

Универсальная локальная PWA: программы не привязаны к 16 неделям.

Включает: Сегодня, календарь, универсальные программы, конструктор тренировок, библиотеку упражнений, кардио, силовые подходы, RPE/энергию/заметки, вес, цели, шаблоны, импорт/экспорт JSON, тёмную тему и offline cache.

Для iPhone разместите файлы на HTTPS и откройте URL в Safari: Поделиться → На экран «Домой».
