# Fitness Planner Pro
PWA для личного фитнес-плана.

Включает календарь, 16 недель, чек-листы, бег, силовые подходы с весом/повторами, RPE, энергию, заметки, вес, прогресс, импорт/экспорт JSON, тёмную тему и offline cache.

Данные хранятся локально в браузере. Для установки на iPhone нужен HTTPS-хостинг, затем Safari → Поделиться → На экран «Домой».

Встроенный план является стартовым шаблоном. Его следует заменить на фактическую персональную 16-недельную программу.
